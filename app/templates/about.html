MediaSync

Library Automation

MediaSync keeps your media stack responsive by connecting acquisition tools directly to your media server. Movies scan immediately, TV imports are handled with queue-aware smart sync, and live activity monitoring keeps library updates visible without app-hopping.

Built for Flow

MediaSync watches for completed imports and triggers the right mapped library scans automatically. The goal is simple: newly available media should appear quickly without manual refreshes or repeated app checks.

Connected Stack

Designed around real home media workflows, MediaSync brings sources, libraries, queue-aware scan behavior, and activity history into one clean operational view.

What's Next

MediaSync is evolving toward full media pipeline visibility. Upcoming releases will expand media server support with Plex and Jellyfin, add downloader awareness, and introduce deeper tracking across the path from request to availability.

The long-term goal is a single pane of glass for the full workflow: Seerr -> Arr -> Downloader -> MediaSync -> Media Server, with future processor integrations like Unmanic for transcoding status, storage optimization, and space savings insight.
